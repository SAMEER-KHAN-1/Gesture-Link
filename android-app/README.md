# GestureLink Android App

Kotlin + Jetpack Compose app that pairs with `pc-server` and sends it commands.

## Opening the project

Open the `android-app` folder in Android Studio (Koala or newer) as a project.

One thing to know: this repo does **not** include the binary Gradle wrapper jar (`gradle/wrapper/gradle-wrapper.jar`) - it's a committed binary blob that's better generated by tooling than hand-written. `gradle-wrapper.properties` (which Gradle version to use) is already there. When you open the project, Android Studio will notice the wrapper is incomplete and offer to regenerate it automatically; accept that prompt and it'll fetch Gradle 8.7 and finish setting itself up. After that, `gradlew`/`gradlew.bat` work normally like any Android project.

## What's here so far

Just the project skeleton - Gradle setup, manifest, a placeholder launcher icon, and a single Compose screen that renders "GestureLink" so we can confirm the app builds and installs before wiring up any real functionality. Pairing, the dashboard, and the WebSocket client are coming in the next commits.
